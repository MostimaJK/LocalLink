# 启动、网络与限速检查（2026-11-21）

## 已完成

- 通用 → 接收后下方增加「传输限速」，发送/接收分别设置不限速、1、5、10、25、50、100 MB/s，默认不限速。使用现有三语言自定义下拉框。
- 存入 SQLite `locallink.bandwidth`；启动读取，修改时立即更新当前传输实例。每个方向共享一个预算，多任务不会各自占满限额。限制的是文件有效载荷，不含发现、文字、TLS/TCP 开销和旧协议/通话。
- 发送通过流式节流，接收通过背压控制；接收端及操作系统缓冲区会造成短时突发，不是路由器级 QoS，也不能替其他程序限速。不限速走快速路径，保持背压、取消和 SHA-256 校验。
- 启动恢复中断任务改为利用状态索引只读取未完成记录，不再读取并解析全部成功历史。保留已完成任务不变。

## 本轮测量

所有文件测试均使用生成文件、临时目录和本机接收端，没有向真实附近设备发送用户文件。

| 检查 | 结果 | 范围 |
| --- | --- | --- |
| 活跃网卡 | Realtek 有线 1 Gbps | 本机链路速率；Wi-Fi 未连接，不能据此判断路由器或另一台电脑 |
| 500 MiB 不限速，修改前 | 2.70 秒；进程峰值 RSS 137 MiB | 两端在同一 Node 进程，本机回环；包含发送前哈希 |
| 500 MiB 不限速，修改后 | 2.74 秒；进程峰值 RSS 121 MiB | 单次样本不是统计性性能提升/退化结论 |
| 2 MB，发送限速 1 MB/s | 2.02 秒，内容一致 | 本机真实 HTTPS |
| 2 MB，接收限速 1 MB/s | 2.02 秒，内容一致 | 本机真实 HTTPS |
| 两个并发流合计 2 MB、总限速 1 MB/s | 2.00 秒 | 共享预算测试；另测实时取消限速与销毁 |
| 新资料启动到设置可操作 / 网络就绪 | 1577 / 1601 ms | Playwright Electron，禁用 GPU，非操作系统冷缓存 |
| 两次重复启动到设置可操作 / 网络就绪 | 1216 / 1240、1170 / 1205 ms | 同一临时资料；不是用户真实大量历史资料 |
| 20001 条历史的中断恢复 | 原全量读取过滤 21.54 ms，新索引恢复 0.36 ms | 内存 SQLite 微基准，不等于整机启动提速比例 |

1 Gbps ÷ 8 = 125 MB/s 是链路理论上限，文件吞吐还需扣除协议开销。回环约 191 MB/s 表明此机器上的传输代码有千兆处理余量，但不能宣称经过实际路由器已经跑满；磁盘、对端 CPU、网口、无线信号、交换路径都会限制速度。

## 仍应开发或优化（按优先顺序）

1. **双机基准**：两台有线电脑，比较链路测试与真实文件传输；分别记录预处理、网络发送、落盘确认耗时，测试多文件和双向同时发送。当前结果不替代双机实测。
2. **启动迁移收敛**：`database.js` 每次构造仍调用 `migrateFromElectronStore(true)`，实际还复制设置/身份/朋友；应先补新旧资料迁移测试，再改为有版本标记的一次性头像补偿，避免贸然改变存储来源。启动还同步检查旧附件，需大资料下量测再移出首屏关键路径。
3. **首次发送等待**：为完整性校验，当前先完整读取源文件算 SHA-256，再读一遍上传；文件夹先生成不压缩 ZIP 再计算哈希。需要区分准备进度与传输进度，并评估后台哈希/归档与安全缓存，不能为速度去掉校验。
4. **小文件吞吐**：同一批次顺序发送，每个请求 `agent:false` 重新建 TLS；评估受控并发与安全连接复用，同时保留证书指纹验证和按开始时间排序，不能盲目提高并发。
5. **网络变化**：已有逐网卡 IPv4 组播，10 秒公告周期；缺少完整 IPv6 和物理切网/休眠恢复压力验证。继续验证多网卡重复设备、VPN 路由和重连。
6. **大文件与续传**：当前会话仍限制 500 MiB，失败重试从头发送；提高上限需补长时间慢速、磁盘空间与中断测试。续传需单独设计，不能把重试称为续传。
7. **通讯范围**：此次限速针对默认 LocalSend 文件通路；LocalLink 原生文字仍可用，语音视频仍是保留的旧协议能力，尚未统一到默认连接。iOS/Android 与原版 LocalSend 双机验收仍需单列。
