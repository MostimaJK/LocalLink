# 右键菜单本地化修复（1.0.0）

截图问题来自侧栏直接调用旧聊天菜单，而非语言设置未保存。

- LocalSend 设备使用独立设备菜单：收藏/取消收藏、设备信息与备注、配对授权、复制设备 ID。
- 不再展示对这些设备无效的旧举报、互联网连接、个人资料和关闭私聊入口；旧模式对应代码保留。
- 共用菜单按当前语言翻译固定操作标签，覆盖消息操作、文件/图片/文件夹发送、通话、群组和文件夹的常用菜单。未知动态标签原样保留，避免翻译用户命名内容。
- 复制 ID 提示补齐三语。三语言实际设备右键测试及菜单词表测试通过；截图 artifacts/context-menu-translated.png。
- 不是全工程英文字符串清零：旧连接向导、历史社交功能的动态提示仍需单独审查。本轮未修改网络和用户数据结构。
- 运行中的旧便携包被占用，因此另生成 LocalLink-1.0.0-Portable-menu-fix.exe，内部版本仍为 1.0.0。请从托盘退出旧实例再启动修复包。
