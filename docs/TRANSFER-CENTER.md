# 导航：设备、传输任务、已接收文件

1.0.0 源码增量；本轮不构建 EXE。

- 双向箭头入口为跨设备传输任务页，显示进行中/失败与取消/已完成；进行中数量徽标最多显示 999+。支持真实字节进度、取消、失败重试及 PIN 输入。
- 文件夹入口为已接收文件页，按文件名搜索及图片/文本/归档分类，提供打开、所在目录、按需图片预览、勾选清理（沿用回收站确认流程）。原生文字消息没有文件，因此不列入文件库；兼容 TXT 文件仍列入。
- 使用原 SQLite 传输索引表；SQL 过滤后每页 100 条，不复制历史。接收页保留已清理记录但禁用文件操作，外部手动移动/删除通过打开错误反馈，不误报成功。
- 页面共享设备侧栏，查看设备回到原会话；搜索与筛选在本次运行中保留。任务事件节流刷新，保留搜索输入和已勾选项目。
- 原记录弹窗及设置里的备份、保存路径、缓存清理保留。

验证：实际 Electron 导航/筛选/空状态/徽标/返回会话测试；取消和重试按钮在隔离进程中验证 IPC 参数；真实传输工作流沿用现有独立 HTTPS 接收测试。截图中的任务和路径为测试数据，不是实际用户文件。SQL 筛选由 SQLite 单测验证。未声称断点续传、离线队列或图片全尺寸查看器已实现。
