# LocalLink 1.0.3

桌面端新增手机浏览器双向传文件。打开「与手机互传」，选择与手机同一局域网的网卡，点击绿色「开始共享」。手机扫码并输入六位配对码即可收发文件，无需安装客户端。

- 地址菜单显示 IP 和网卡名称，常见虚拟接口排在后面。
- 收起二维码面板后，可以从标题栏继续选择文件。红色「结束共享」会撤销旧链接并停留在面板，可直接开始下一次共享。
- 配对前的邀请有效期为 15 分钟。每个会话限一个已配对浏览器，上传限 100 个文件、合计 1 GiB。
- 支持部署受信任证书的 HTTPS。HTTP 模式只适合可信私人网络传送非敏感文件。
- 精简桌面语言、图标和数据库打包资源，改进文件夹打包及临时文件清理。

Windows x64 提供安装版与便携版，macOS 提供 Apple Silicon 和 Intel 两种 DMG。Windows 程序未签名，Mac 程序使用临时签名且未经 Apple 公证。可使用随附的 SHA256SUMS.txt 核对下载文件。
