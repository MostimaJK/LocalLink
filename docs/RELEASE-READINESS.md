# LocalLink 1.0.0 发布前检查

日期：2026-11-21。范围：当前工作树，Windows x64 开发运行与源码发布准备。**结论：可以作为明确标注限制的 Windows 发布候选源码供审查；不能宣称已经完成全平台正式稳定发行验收。** 本次没有上传 GitHub、创建 Release、打标签或制作新 EXE，遵循此前暂不打包的要求。

## 本次增加与修正

- 设置 → 诊断 → 网络适配器检测：手动检测 Windows 网络适配器、连接状态、发送/接收链路比特率及换算 MB/s。区分 有线 / WLAN / 蓝牙 / 其他 / 虚拟网卡。未连接时不显示驱动残留速率；未报告速率时显示未知。多个适配器的速率不相加，也不猜测当前文件实际路由。
- 主进程使用固定 `Get-NetAdapter` 命令和绝对 PowerShell 路径，隐藏窗口、10 秒超时、1 MiB 输出上限、5 秒缓存及并发请求合并。无管理员提权、无网络测速流量、无资料上传；不加入启动关键路径。非 Windows 给出明确不支持提示。
- 重写 README / SECURITY 为 LocalLink 当前支持范围；上游 README 移到 docs/upstream，不再混淆产品主页。移除上游邮箱和公钥代表 LocalLink 的错误声明。版本仍为 1.0.0。
- GitHub 测试增加 push；Windows 发布候选构建改为手动触发、测试通过后生成校验文件及 artifact，移除自动发布和未经验证的多平台 Release 声明。没有执行远端 workflow。
- 新增 `npm --prefix desktop run test:release`，含默认协议核心测试、SQLite 迁移/备份/历史恢复与 14 项主要界面测试。旧 UI 测试仍保留，不把这组门禁当作全部遗留测试已通过。
- 111 个已安装生产依赖的声明及可取得许可证文本汇总到 desktop/THIRD-PARTY-NOTICES.txt，并加入构建资源；上游 LICENSE 保留。补充忽略本地私钥身份文件、签名容器、数据库 WAL/SHM 等。relay 新增锁文件。

## 正式稳定发行前仍需完成

1. **真实双机验收**：LocalLink↔LocalLink、LocalLink↔原版 LocalSend 的 Windows/Android/iOS 文件互传；有线/Wi-Fi、取消/拒收/离线、切网/休眠；不把本机两端替代此验证。
2. **二进制验收**：干净 Windows 机器的安装、便携运行、旧资料升级/卸载保留与回滚。当前已取消 500 MiB 容量上限，续传未实现，通话仍在旧协议。
3. **依赖与资产许可补全**：qrcode-generator 有源文件 MIT 声明，type-fest 有 MIT OR CC0 声明但安装包无独立全文；需要补齐发布所需文本，并核对上游附带图片/头像框等资产来源。当前清单不是法律合规认证。
4. **仓库公开检查**：开发 screenshots / docs 可能包含本机路径、设备昵称；完整 Git 历史的秘密扫描尚未执行。检查后再公开，真实凭据如泄漏应轮换而非仅删文件。
5. **发布渠道配置**：维护者启用 GitHub 私密漏洞报告；确定 LocalLink 签名身份/校验发布渠道，不沿用上游公钥。Windows/macOS 未签名状态不得隐瞒。
6. **Android 告警与平台支持**：处理依赖升级并在设备重验后才能发布 Android；当前没有 LocalLink iOS 客户端。移动与旧通信路径未经过本轮全量 E2E。

相关报告：artifacts/release-audit-{all,production,mobile,relay}.json。npm audit 结果只对应执行时的锁文件及公告数据库。

## 容量限制更新

已解除默认发送、接收和文件夹 ZIP 的 500 MiB 容量限制。保留整数合法性、磁盘空间、校验及元数据/数量保护：每批最多 100 个文件，文件夹最多 10000 条目，消息/图片粘贴仍有独立限制。文件夹仍需临时 ZIP 磁盘空间。600 MiB 单文件通过实际回环 HTTPS 收发与校验；600 MiB 文件夹归档通过；未执行 50 GB 实测。协议、任务生命周期和文件夹测试通过。此更新不表示安装包已重新构建或已恢复发布。
