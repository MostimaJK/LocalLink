# 通用设置整合

本设备、网络、通知、资料管理合并为“通用”（繁简中文相同；英文 General）。外观、诊断与关于保持独立。

显示顺序：
1. 接收与保存：保存位置优先，更改/打开文件夹、重新发现设备。
2. 接收后：完成后打开所在文件夹开关。
3. 设备名称、界面语言。
4. 传输通知。
5. 传输记录、备份、发送缓存清理。
6. 不常用的进阶连接选项。

复用原有各部分的操作和持久化，原来的 network/notifications/data 设置入口和最后访问记录自动归入通用。不改变协议、接收路径、数据库或设备身份。

验证：Electron Playwright 通用设置、语言、窗口与菜单、会话、传输工作流共 8 项测试通过（旧分栏断言更新后重跑通过）；语法与 diff 检查通过。检查了页面顶部/底部截图，1000×680 窗口下更改文件夹按钮无需滚动可操作。传输测试使用本机独立接收端，覆盖指定目录保存与接收后打开文件夹，不代表两台实体电脑的新一轮验证。本轮不打包 EXE。
