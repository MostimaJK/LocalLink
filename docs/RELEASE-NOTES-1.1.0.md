# LocalLink 1.1.0

- Confirm or cancel dropped files in the conversation before sending.
- Incoming messages scroll into view. When reading older messages, a shortcut returns to newly sent items.
- Copy images at their original resolution. Clear one received image or sent screenshot cache from its card, with the result shown in place.
- On Windows, enable administrator startup in General settings. Restart prompts can be cancelled. Fixed a launch failure when the previous process had already exited during elevation.
- Windows packages omit test output and native modules for other platforms.
- Device details places the trust action beside the pairing status. The phone QR panel keeps its file picker, and the group conversation lists shared files and messages.
- Image copy uses the Electron clipboard API and shows a brief confirmation beside the image after the write completes.
- With the Windows Setup edition, choose **Download, install and restart** to verify the package, close LocalLink, install in place and reopen it. Settings → About can retry an interrupted installation using the verified local package.
