## 当前状态

Windows 已有附近发现、收藏、设备名称/本机备注、文件会话、三语言基础界面和单文件 HTTPS 传输。产品仍处于传输协议预览阶段：完整收发任务管理、统一历史/存储管理、真实原版客户端互测和 Android 新协议尚未完成。

## 界面与产品收敛

1. 主流程保持“设备列表 + 文件会话”，不再另起一套传输页面。
2. 整理重复的记录/全部记录，以及活动中心、画廊和存储入口；先接通新传输数据，再判断哪些入口可合并。
3. 群组降级为旧记录/候选设备组，先定义多设备发送行为；不要直接抹掉旧历史。
4. 语音/视频保留为后续 LocalLink 增强能力。现在只能经旧连接使用，不能声称 LocalSend 设备支持通话。
5. 设置收敛为本设备、传输与存储、外观、通知、诊断、关于。仍有大量社交/实验、头像效果、消息动画、双 UI 等旧选项，逐项移出正常产品路径；保留减少动态效果和基础主题缩放。
6. 补齐原生接收/错误弹窗、通知、提示标题及旧设置的繁简英文案；连接弹窗和新旧路径术语仍不一致。语言切换测试通过不等于全应用已翻译。
7. 成功通知、接收请求和失败通知统一数据，合并同一失败的 IPC 错误/任务 Toast，避免重复提示。
8. 更新首页能力说明；目前仍提及文字/链接等，实际默认新协议尚未支持，不应让用户误判。

## 建议实施顺序

1. **可靠性修复**：备份恢复、手动发现入口、活跃传输超时、接收任务失败记录。补回归用例。
2. **传输任务与存储**：真实进度/取消/重试、目录设置、统一任务持久化；原版 LocalSend 双机验收与之并行。
3. **聊天式发送体验**：多文件、拖放、粘贴图片、文本/链接、缩略图；保持原文件完整。
4. **历史与产品整理**：统一搜索、画廊、通知和清理，补齐语言，合并旧入口与双 UI。
5. **发行及扩展**：Windows 安装/升级、配对授权、Android；通话增强、跨网、断点续传和历史同步分别验收，不一起打包成一个重构。
