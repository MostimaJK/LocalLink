# 界面与接收设置微调

本轮按 uiux-product-designer skill 做局部修改，沿用现有布局与 Lucide，不生成 EXE。

- 目录操作、备份及文件卡片操作采用实体按钮；保留点击行为。
- 设备行选中背景包含右侧收藏按钮，收藏区有独立点击区域。
- 顶部设备导航使用 monitor-smartphone 线条图标，移除底部重复本设备入口；保留设置，本设备设置仍在设置内。
- 通知、减少动态效果、接收完成打开文件夹使用可键盘操作的 switch。
- 设置→网络新增接收后分区及持久开关 locallink.openAfterReceive，默认关闭；收到文件并保存成功之后调用系统显示所在位置，不自动执行文件。
- 保存行为一直存在：接收确认后写入指定目录内的独立 transfer-* 子目录，临时文件校验成功才完成保存；保持防覆盖策略。自动接收仅限已配对且明确授权设备。

验证：三语设置、真实独立 HTTPS 接收、指定目录内保存、源文件字节一致、自动打开路径回调、选中行包含收藏按钮与导航 DOM 回归通过。系统资源管理器调用在测试中截获核对路径，不宣称已完成两台物理电脑实测。截图见 artifacts/receive-settings-refined.png 与 transfer-workflow-compact.png。
