# LocalLink 1.0.8

- 桌面文件夹直接传输并保留目录结构。空目录会列在跳过清单中，大批文件可以在聊天中展开查看。
- 两台 1.0.8 桌面设备通过 HTTPS 重试时，会先核对原接收端的文件回执。已完整保存且没有变化的文件可直接确认；中途断开的单个文件仍需从头发送。
- 手机扫码群支持取消发送。成员失联约 90 秒后退出待确认名单，在线成员继续使用设置中的确认时限。
- 备份支持电脑与扫码传输的混合历史。导出原文件时核对身份，并列出缺失、已替换或无法确认身份的文件。升级前没有身份信息的旧记录仍可备份为记录。
- 恢复备份时保留文件名和相对目录，重新登记文件身份。导入失败会清理本次产生的副本；导出与导入使用相同的清单大小和数量限制。
- 接收临时文件支持异常退出后回收。发送缓存区分正在发送、保留供重试及可清理文件。手动连接的设备过期后会在发送前重新探测。

Windows x64 提供安装版与免安装版。macOS 提供 Apple Silicon 与 Intel 两种 DMG。四个下载包的 SHA-256 均列于 SHA256SUMS.txt。
